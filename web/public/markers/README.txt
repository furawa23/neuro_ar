NeuroAR camera marker

The printed image and binary payload are generated by this project. Print at
actual size: the outer black edge measures 140 mm; keep the white margin.
The interior-to-black-square pattern ratio is 5/7.

neuroar-marker.patt is generated by web/scripts/generate-pattern.mjs from the
same 5x5 payload used in the printable SVG and PNG. Do not replace only one
of those assets; regenerate the matching pattern and run the marker tests.

camera_para.dat is the generic example calibration file distributed by AR.js
3.4.8, retrieved from:
https://github.com/AR-js-org/AR.js/blob/3.4.8/data/data/camera_para.dat
It is not a calibration measured for the Xiaomi Redmi Note 12S. Alignment and
physical scale remain approximate until they are tested on the device.
